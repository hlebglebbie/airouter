    Добавить API

    Можно добавить несколько ключей одного сервиса — каждый ключ отдельной записью. Роутер сам переключится на рабочий.

    Как это работает

    • Endpoint: POST http://localhost:5959/v1/chat/completions — модели fast и think.
    • fast → модель с самым быстрым ответом (замер по одному слову).
    • think → модель с наибольшим числом параметров (оценка по имени).
    • При сбое API запрос автоматически уходит на следующий рабочий; ожившие API возвращаются в ротацию.
